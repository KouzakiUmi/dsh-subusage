# UX 设计定稿（v2，2026-09-30 拍板）

状态一眼可读、语义零歧义、颜色=状态。本文是界面实现的权威来源；改动 UI 前先读。

## 设计原则

1. **颜色管状态、文字管语义、条管趋势**——三重编码，不读数字也能判断"能不能用"；
2. **数字永远带限定词**：药丸答"还能用多少"（`余 87%`），详单答"用了多少"（`已用 13%`）；
3. **不可用是视觉事件**：整行淡红底 + ✕ 徽标，扫一眼就跳出来；
4. 系统态图标只在异常时出现（🟡 读取中 / ⚙ 需配置 / 🔴 拉取失败），正常时不打扰。

## 档位色板（全界面统一，实现见 client.js 的 `usageTier()`）

| 已用 | 状态 | 色 | 徽标 | 数字色 |
|---|---|---|---|---|
| 0–70% | 可用 | 绿 `#22c55e` | ✓ 可用 | 白（前景） |
| 71–90% | 偏高 | 黄 `#eab308` | ⚠ 偏高 | 黄 |
| 91–99% | 紧张 | 橙 `#f97316` | ⚠ 紧张 | 橙 |
| ≥100% | 不可用 | 红 `#ef4444` | ✕ 不可用 | 「⚠ 已达限额」 |
| 被连坐 | 不可用 | 红 `#ef4444` | ✕ 受连累 | 「⚠ 暂不可用」 |

## 小药丸（收起态）——信息压缩极致

**不显示厂商名**（右侧模型选择器即语境），**最差窗优先**（限额时指根因窗而非被连坐窗）：

```
[✓ 余 87%]          全部充裕（绿✓ 白字）
[⚠ 7d 余 12%]       偏高/紧张（黄/橙；多窗带窗口短名）
[✕ 7d 已达限额]      红✕ + 药丸淡红底
[⚙ 需配置] [🟡 读取中] [🔴 拉取失败]
```

- 单窗厂商（MiMo）省略窗口短名：`[✓ 余 53%]`；
- 空间只花在"当前最要紧的一窗"上，其余点开看。

## 窗口行（药丸弹层与设置页共用 `UsageWindowRow`）

```
5 小时  [✓ 可用]                已用 13%
[████████░░░░░░░░░░░░░░░░░░░░]        ← 条=已用，颜色随档位
已用 13 / 100 点 · 重置于 今天 14:58（还有 9 小时）
```

- 不可用行整行淡红底 + 红描边；连坐行尾注「（受更长周期限额连累，暂不可用）」；
- 重置时间带倒计时；到期未刷新显示「已到重置时间，等待刷新」。

## 设置页 tag 圆点

挂**最差窗口档位色**（绿/黄/橙/红），拉取失败红——决策价值高于"拉取成功"状态。

## 拍板记录

- 窗口行主数字 = **已用 %**（与进度条同向；余量在副行/药丸呈现）；
- 徽标 = **图标 + 文字**（色弱可读）；
- 药丸 = **最差窗优先且去掉厂商名**（模型选择器已含语境）。
